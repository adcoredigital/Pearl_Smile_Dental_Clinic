# Pearl Smile Dental Care — GitHub Pages

Combined Stitch static website.

Pages:
- index.html — Home
- about.html — About
- treatments.html — Treatments
- doctors.html — Doctors
- contact.html — Contact & Appointments

## Launch on GitHub Pages
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. GitHub will publish `index.html`.

The Stitch design uses externally hosted fonts/CDN resources, which can load from GitHub Pages over HTTPS. Appointment/contact forms are front-end only and need a form service/backend for real submissions. Replace any placeholder phone/email/map details before launch.
